#### Room Booking System
Room booking system is a web application that allow users to book rooms without any hassle. 

#### Features
No double booking conflict 
Room visibility 

#### Tech Stack
Frontend: React.js + Tailwind 
Backend: Node.js + Express + PostgreSQL 

routes: define URL 
|
middleware: protect and validate request (authentication, validation), checking for token
|
controllers : handle request and response (extract and respond with data)
|
services : business logic (contain business logic)
|
utils : prisma(database connection), jwt(authentication), etc
